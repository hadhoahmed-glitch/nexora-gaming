# Nexora-Gaming

منصة ألعاب عربية Front-End جاهزة كبداية.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## الموجود
- واجهة Gaming حديثة ومتجاوبة
- مكتبة ألعاب
- بحث وتصنيفات
- أخبار
- بطولات
- نافذة تسجيل دخول تجريبية
- مجتمع اللاعبين

## التطوير القادم
لتحويلها لمنصة حقيقية: Backend + قاعدة بيانات + حسابات حقيقية + لوحة تحكم + API للأخبار والألعاب.
